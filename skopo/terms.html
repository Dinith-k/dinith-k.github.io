Using Skopo

Skopo is provided by Aplogon, an independent app developer based in Sri Lanka. It opens files you choose and shows them as a JSON or XML tree, a CSV table, text and logs, or bytes in a hex view, with search, copying, editing, saving, converting and sharing. By using the app you agree to these terms. You must be at least 16 years old to use Skopo.

Your files

Only open, edit and share files you have the right to use. Skopo reads JSON, CSV, XML and text the way their common standards describe; it checks that JSON and XML are well formed, but it does not validate files against schemas, run any code in them, or guarantee that every file, dialect or encoding reads the way another program reads it. When a file isn't valid, Skopo says where, and you can still open it as text or hex.

Changes you make in Skopo are written to a file only when you save. Replacing a file overwrites it, which cannot be undone in Skopo, so keep a copy of anything important before you save over it. Skopo asks you to confirm before it replaces a file.
