About Skopo

A viewer for developer files: JSON and XML as trees with search, validation and paths, CSV as a sortable table, logs with level filters, and any file in a hex viewer and editor. Big files open smoothly, a piece at a time. Skopo needs no storage permission: you open each file from Android's file picker or from another app, and your files are never uploaded.
